# Screenshots

Place screenshots captured while completing the lab in this directory.

## Naming Convention

Use:

`activity-XX-task-description.png`

Examples:

- `activity-01-directory-structure.png`
- `activity-03-secure-permissions.png`
- `activity-06-hosts-ping.png`
- `activity-09-hello-script-output.png`
- `activity-10-system-monitoring.png`

Use lowercase names with hyphens. Keep screenshots readable and include enough terminal context to identify the command/output.

Do not place fabricated screenshots here. The repository contains `.gitkeep` only until real evidence is captured.
