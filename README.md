# Linux Practical Test Package

A GitHub-ready project structure for the **Linux Practical Test Package** lab. This repository organizes the ten activities from the supplied lab instructions into separate, beginner-friendly directories.

> **Important:** This repository contains the lab structure, commands, scripts, documentation, and evidence placeholders. It does **not** claim that any lab activity has been completed. Capture your own screenshots and terminal output as you perform the tasks.

## Lab Activities

1. Navigation & File Management
2. File Viewing & Editing
3. Permissions & Ownership
4. Archiving & Compression
5. Process Management
6. Networking Basics
7. Searching & Finding
8. Package Management (Debian/Ubuntu-based)
9. Scripting Basics
10. System Monitoring & Logs

## Repository Layout

- `activities/` — activity-specific notes and task checklists.
- `scripts/` — reusable scripts required by the lab.
- `commands/` — command references and command-by-activity documentation.
- `screenshots/` — screenshots captured while performing the lab.
- `evidence/` — organized evidence records/placeholders.
- `docs/` — supporting documentation.
- `backup/` — space for lab-created backup/archive artifacts where appropriate.

## How to Use

1. Work through the activities in order.
2. Run commands in your Linux environment rather than merely copying them into this repository.
3. Create screenshots at the evidence points listed in `EVIDENCE_CHECKLIST.md`.
4. Store screenshots using the naming convention in `screenshots/README.md`.
5. Record any environment-specific differences or permission issues in the relevant activity README.
6. Commit the completed project to Git when ready.

## Source

This structure is based primarily on the supplied **Linux Practical Test Package** instructions. The lab specifies ten activities covering files/navigation, permissions/ownership, archiving/compression, processes/networking, searching/package management, scripting, and system monitoring.
