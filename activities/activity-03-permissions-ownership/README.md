# Activity 03 — Permissions & Ownership

## Lab Tasks
- Create `secure.txt`.
- Give owner read/write, group read-only, and others no permissions.
- Change permissions to `777`.
- Create user `student2` if permitted.
- Change `secure.txt` owner to `student2`.
- Verify with `ls -l`.

The requested initial permission mode corresponds to `640`; the later explicit `777` requirement changes the state.
