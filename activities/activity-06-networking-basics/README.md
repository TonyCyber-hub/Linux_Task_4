# Activity 06 — Networking Basics

## Lab Tasks
- Display IP information with `ip a`.
- Test connectivity with `ping google.com -c 4`.
- Check listening ports with `ss -tulnp`.
- Find the hostname with `hostname`.
- Add `127.0.0.1 testsite.local` to `/etc/hosts`.
- Ping `testsite.local` to verify.

Changing `/etc/hosts` may require administrative privileges.
