# Activity 10 — System Monitoring & Logs

## Lab Tasks
- Display disk usage with `df -h`.
- Check memory with `free -h`.
- Display the last 10 system log entries from `/var/log/syslog` or `/var/log/messages`.
- Use `uptime`.
- Show logged-in users with `who`.
- Display CPU information with `lscpu`.

Log-file availability can vary by Linux distribution; use the path specified by the lab that exists on your system.
